# explore-css-logos

A collection of logos built with pure CSS — exploring shapes, animations, and creative styling through code.

## Logo: Nuno Alves Brand

The current logo features an animated brand mark with two overlapping circles ("n" and "a") and a description section, built entirely with CSS keyframe animations.

### Animations

- **Circle N**: Slides in from the right (`toLeft`)
- **Circle A**: Slides in from the left (`toRight`)
- **Name**: Fades in with a delay
- **Role**: Fades in with a longer delay

## Usage

Open `index.html` in any modern browser to see the logo in action.

No build tools or dependencies required — just HTML and CSS.
